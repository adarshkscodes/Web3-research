# Web3-research

**Web3 Project Analysis: Uniswap (DEX Protocol)**
*Prepared by: Adarsh Kumar*

---

### 1. Overview

Uniswap is a decentralized exchange (DEX) built on Ethereum that enables users to swap tokens without intermediaries. It uses an automated market maker (AMM) model instead of traditional order books.

---

### 2. Problem it Solves

* Eliminates need for centralized exchanges
* Enables permissionless token trading
* Provides liquidity without market makers

---

### 3. Architecture Analysis

* Smart contracts manage liquidity pools
* Uses AMM formula: x * y = k
* Liquidity providers (LPs) deposit token pairs
* Fees distributed to LPs

---

### 4. Tokenomics (UNI Token)

* Governance token (voting rights)
* No direct revenue share
* Used for protocol decision-making
* Distributed via liquidity mining and airdrops

---

### 5. Strengths

* Fully decentralized and permissionless
* High liquidity and adoption
* Simple and robust architecture
* Strong developer ecosystem

---

### 6. Risks & Limitations

* Impermanent loss for liquidity providers
* Front-running / MEV risks
* High gas fees (on Ethereum)
* No built-in KYC or compliance

---

### 7. Real-World Impact

Uniswap has become a core infrastructure layer of DeFi, enabling thousands of tokens to be traded without centralized control.

---

### 8. Personal Insights

Uniswap’s success comes from simplicity and strong incentives. However, scalability and MEV issues highlight the need for Layer 2 adoption and protocol-level improvements.

---

### 9. Conclusion

Uniswap is a foundational DeFi protocol with strong product-market fit, but long-term sustainability depends on scalability and improved economic incentives.
